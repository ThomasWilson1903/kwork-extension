# Kwork Dark

Расширение для Chrome и Edge, которое перекрашивает kwork.ru и kwork.com в тёмную тему.

## Установка

1. Открыть `chrome://extensions` (или `edge://extensions`).
2. Включить «Режим разработчика».
3. Нажать «Загрузить распакованное расширение».
4. Выбрать папку с `manifest.json` — корень этого проекта.

Тема включается сразу после установки. Отдельного разрешения не нужно: в манифесте только `storage` и два домена.

## Управление

- Клик по иконке на панели инструментов — переключение темы. Бейдж показывает `ON` (тёмная) или `OFF` (светлая).
- Плавающая кнопка «Светлая» / «Тёмная» в правом нижнем углу страницы — то же самое.
- Настройка хранится в `chrome.storage.local` под ключом `kwdEnabled` и переживает перезагрузку, вкладки и переходы между страницами.

## Как устроено

| Файл | Назначение |
| --- | --- |
| `manifest.json` | MV3-манифест: домены, content script, service worker |
| `src/css/tokens.css` | Переопределение всех 89 токенов `--color-*` сайта + собственные `--kwd-*` |
| `src/css/base.css` | Фон страницы, `color-scheme`, скроллбары, формы, димминг изображений, стили кнопки-переключателя |
| `src/css/components.css` | 20 секций: глобальный защитный контур, возврат белого текста, legacy-bootstrap, fox-styles, база знаний, загрузчик файлов, портфолио, лендинги |
| `src/content.js` | Состояние темы, кнопка на странице, реакция на storage-события, клавиатура |
| `src/background.js` | Клик по иконке и бейдж |

### Как включается тема

Тема тёмная по умолчанию: правила записаны как `:root:not([data-kw-light])`. Светлый режим — это атрибут `data-kw-light` на `<html>`, который ставит `content.js`. Так сайт остаётся тёмным до того, как расширение успеет загрузиться, и не мигает белым при первом открытии вкладки.

### Как решена проблема «белый текст на белом фоне`

Главная причина сбоев — токен `--color-typography-white`. Kwork использует его и как цвет фона (349 вхождений), и как цвет текста (399 вхождений), поэтому оставить его белым нельзя: на белых подложках появляется невидимый текст.

Решение — перевернуть токен в тёмную поверхность и вернуть белый цвет точечно:

| Токен | Значение | Зачем |
| --- | --- | --- |
| `--color-typography-white` | `#1c1f26` | Перевёрнут: любое `background: var(--color-typography-white)` становится тёмным |
| `--color-typography-white-rgb` | `28, 31, 38` | Для выражений вида `rgba(var(--color-typography-white-rgb), .5)` |
| `--color-typography-white-secondary` | `#171a20` | Вторичные белые подложки |
| `--kwd-white` | `#ffffff` | Наш собственный «белый» — только для текста, который реально лежит на цвете или фотографии |

Белый текст возвращается явным списком селекторов в `components.css` (секции 1 и 1a): кнопки, плашки, уведомления, заголовки поверх фото, header, `/for-sellers`, просмотрщик изображений. Так один токен не может «протечь» на сотни неизвестных классов.

Поверх фотографий и очень светлых подложек текст остаётся белым, но под ним кладётся тёмный слой: например, `.land-video-show__footer` на `/for-buyers` перекрывается `rgba(16,18,22,.64)` — фото остаётся видимым, а контраст белого текста получается 5.42:1.

### Контраст

Акцентные токены (`--color-accent-positive-base` и другие) намеренно яркие: они работают как цвет ссылок, иконок и индикаторов на тёмном фоне, где нужен высокий контраст. Но на кнопках и плашках лежит белый текст, а поверх яркого тона он нечитаем — поэтому для таких поверхностей в `tokens.css` заведены отдельные затемнённые токены `--kwd-on-*`, которые дают белому тексту 4.5+ (WCAG AA):

| Токен | Значение | Контраст с белым |
| --- | --- | --- |
| `--kwd-on-primary` | `#0a6fd6` | 4.93 |
| `--kwd-on-positive` | `#178546` | 4.69 |
| `--kwd-on-attention` | `#c2551a` | 4.56 |
| `--kwd-on-negative` | `#d32f2f` | 4.98 |

Изображения приглушаются слабо: `brightness(0.92) saturate(1.05)`. Логотипы, иконки, аватары и просмотрщики изображений не трогаются.
